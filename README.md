 Dominion Jewelry Site

A polished, responsive jewelry storefront landing page for Chilso Jewelers, built as a static HTML/CSS/JavaScript website. The project showcases premium jewelry collections, best sellers, customer testimonials, a gallery, and interactive shopping behaviors without a backend or framework.

## Overview

This repository contains a luxury retail-style homepage for a jewelry brand, designed to feel elegant and modern while remaining lightweight and easy to customize. It includes:

- Hero section with premium branding and call-to-action buttons
- Product collection rail with category tags and pricing
- Search/filtering by jewelry type
- Wishlist and cart interaction buttons
- Animated reveal effects and smooth navigation
- Newsletter signup form and contact/footer sections
- Mobile-friendly responsive layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts
